# ResumeForge 📄

A Streamlit web application to build, customize, and export professional ATS-friendly resumes.

## Features
* **Live Preview:** Real-time resume layout rendering.
* **Templates:** Multiple format styles (Modern, Creative, ATS).
* **AI Assistance:** Generate and refine professional bullet points and summaries.
* **Job Matching & Scoring:** Check keyword relevance against job descriptions.
* **PDF Export:** Download formatted, print-ready resumes.
